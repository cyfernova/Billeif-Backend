# A2A Agent-to-Agent Bargaining Protocol - Complete Guide

## Overview

This guide provides complete step-by-step instructions for testing **automated agent-to-agent bargaining** where buyer and seller agents negotiate prices automatically via A2A protocol, using configurations from `.well-known/agents.json`.

## Base URL
```
http://localhost:8080/api/v1
```

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│          A2A Automated Bargaining System           │
├─────────────────────────────────────────────────────────┤
│                                                       │
│  ┌──────────────┐    ┌──────────────┐              │
│  │ Buyer Agent  │◄──►│ Seller Agent  │              │
│  └──────────────┘    └──────────────┘              │
│         │                     │                     │
│         ▼                     ▼                     │
│  ┌───────────────────────────────┐               │
│  │  A2A Bargaining Service      │               │
│  │  - Reads agents.json         │               │
│  │  - Generates counteroffers    │               │
│  │  - Sends A2A messages       │               │
│  │  - Mentee AI decisions      │               │
│  └───────────┬───────────────────┘               │
│              │                                  │
│              ▼                                  │
│  ┌───────────────────────┐               │
│  │  Mentee Service       │               │
│  │  (AI Decisions)      │               │
│  └───────────────────────┘               │
│                                                 │
└─────────────────────────────────────────────────┘
```

## Prerequisites

1. Authentication token (Bearer token from `/api/v1/auth/login`)
2. Buyer agent created (type: "shopping")
3. Seller agent created (type: "merchant")
4. `.well-known/agents.json` configured
5. Authorization header: `Authorization: Bearer <your_token>`

## New API Endpoints

### 1. Start A2A Automated Negotiation
**Endpoint:** `POST /api/v1/a2a-bargaining/start`

**Description:** Starts automated A2A negotiation between buyer and seller agents that reads configuration from agents.json.

**Request:**
```bash
curl -X POST http://localhost:8080/api/v1/a2a-bargaining/start \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>" \
  -d '{
    "buyer_agent_id": "<BUYER_AGENT_ID>",
    "seller_agent_id": "<SELLER_AGENT_ID>",
    "initial_amount": 100.00,
    "max_rounds": 5
  }'
```

**Response:**
```json
{
  "session_id": "a2a-nego-1234567890",
  "buyer_agent": {
    "id": "<BUYER_AGENT_ID>",
    "name": "Buyer Agent",
    "type": "shopping",
    "endpoint": "http://localhost:8080/api/v1/a2a/message"
  },
  "seller_agent": {
    "id": "<SELLER_AGENT_ID>",
    "name": "Seller Agent",
    "type": "merchant",
    "endpoint": "http://localhost:8080/api/v1/a2a/message"
  },
  "initial_amount": 100.00,
  "current_amount": 100.00,
  "round": 0,
  "max_rounds": 5,
  "status": "running",
  "start_time": "2024-02-10T10:00:00Z"
}
```

---

### 2. Get Negotiation Progress
**Endpoint:** `GET /api/v1/a2a-bargaining/progress/:sessionId`

**Description:** Returns current progress of an A2A bargaining session.

**Request:**
```bash
curl -X GET http://localhost:8080/api/v1/a2a-bargaining/progress/<SESSION_ID> \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>"
```

**Response:**
```json
{
  "negotiation_id": "<SESSION_ID>",
  "round": 3,
  "current_amount": 88.00,
  "action": "in_progress",
  "actor": "seller",
  "timestamp": "2024-02-10T10:03:00Z"
}
```

**Response States:**
- `round: -1` - Session not found
- `action: "not_found"` - Session not found
- `action: "completed"` - Negotiation finished
- `action: "in_progress"` - Negotiation running

---

### 3. Stop Negotiation
**Endpoint:** `POST /api/v1/a2a-bargaining/stop/:sessionId`

**Description:** Stops an active A2A bargaining session.

**Request:**
```bash
curl -X POST http://localhost:8080/api/v1/a2a-bargaining/stop/<SESSION_ID> \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>"
```

**Response:**
```json
{
  "message": "Negotiation stopped",
  "session_id": "<SESSION_ID>",
  "status": "stopped"
}
```

## A2A Message Protocol for Bargaining

### Message Types

#### negotiate.start
**Purpose:** Initiates bargaining session between agents

**Payload:**
```json
{
  "negotiation_id": "a2a-nego-1234567890",
  "round_number": 1,
  "current_amount": 85.00,
  "previous_amount": 100.00,
  "agent_type": "buyer",
  "action": "counteroffer",
  "reason": "Price is too high",
  "confidence": 0.75
}
```

**Action Types:**
- `"counteroffer"` - Propose new amount
- `"accept"` - Accept current offer
- `"reject"` - Reject negotiation

#### negotiate.accept
**Purpose:** Acknowledges and accepts a bargaining counteroffer

**Response Payload:**
```json
{
  "negotiation_id": "a2a-nego-1234567890",
  "round_number": 3,
  "current_amount": 92.00,
  "agent_type": "seller",
  "action": "accept",
  "reason": "Within acceptance threshold",
  "confidence": 0.90,
  "accepted": true
}
```

## Automated Negotiation Flow

### Complete Workflow

```
┌─────────────────────────────────────────────────────────┐
│ Step 1: Start Negotiation                          │
│ POST /api/v1/a2a-bargaining/start                    │
│ → Reads agents.json configs                           │
│ → Creates session with initial amount                    │
│ → Returns session_id                                 │
├─────────────────────────────────────────────────────────┤
│ Step 2: Automated Loop (runs in background)          │
│                                                      │
│   Round 1: Buyer's Turn                              │
│   ├─ Reads buyer config from agents.json             │
│   ├─ Mentee service generates decision               │
│   ├─ Creates counteroffer: $100 → $85              │
│   ├─ Sends A2A message to seller agent              │
│   ├─ Waits 1 second                               │
│   └─ Returns A2A negotiate.accept                  │
│                                                      │
│   Round 2: Seller's Turn                              │
│   ├─ Reads seller config from agents.json             │
│   ├─ Mentee service generates decision               │
│   ├─ Creates counteroffer: $85 → $92              │
│   ├─ Sends A2A message to buyer agent               │
│   ├─ Waits 1 second                               │
│   └─ Returns A2A negotiate.accept                  │
│                                                      │
│   Round 3: Buyer's Turn                              │
│   ├─ Mentee generates decision based on learning      │
│   ├─ Creates counteroffer: $92 → $88              │
│   ├─ Sends A2A message to seller agent              │
│   └─ Returns A2A negotiate.accept                  │
│                                                      │
│   ... continues until:                                  │
│   - Buyer or seller accepts                         │
│   - Max rounds reached                             │
│   - Session stopped manually                         │
├─────────────────────────────────────────────────────────┤
│ Step 3: Monitor Progress                             │
│ GET /api/v1/a2a-bargaining/progress/<session_id>         │
│ → Returns current round and amount                    │
├─────────────────────────────────────────────────────────┤
│ Step 4: Stop (Optional)                             │
│ POST /api/v1/a2a-bargaining/stop/<session_id>         │
│ → Stops automated negotiation loop                    │
└─────────────────────────────────────────────────────────┘
```

## Complete Test Script

```bash
#!/bin/bash

API_URL="http://localhost:8080/api/v1"
TOKEN="<YOUR_JWT_TOKEN>"

echo "=== Step 1: Create buyer agent ==="
BUYER_RESPONSE=$(curl -s -X POST $API_URL/agents \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "type": "shopping",
    "name": "Test Buyer Agent",
    "description": "Buyer for A2A bargaining test",
    "config": {"volatility": 0.4}
  }')

BUYER_AGENT_ID=$(echo $BUYER_RESPONSE | jq -r '.id')
echo "Buyer Agent ID: $BUYER_AGENT_ID"

echo ""
echo "=== Step 2: Create seller agent ==="
SELLER_RESPONSE=$(curl -s -X POST $API_URL/agents \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "type": "merchant",
    "name": "Test Seller Agent",
    "description": "Seller for A2A bargaining test",
    "config": {"volatility": 0.3}
  }')

SELLER_AGENT_ID=$(echo $SELLER_RESPONSE | jq -r '.id')
echo "Seller Agent ID: $SELLER_AGENT_ID"

echo ""
echo "=== Step 3: Start A2A automated negotiation ==="
START_RESPONSE=$(curl -s -X POST $API_URL/a2a-bargaining/start \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d "{
    \"buyer_agent_id\": \"$BUYER_AGENT_ID\",
    \"seller_agent_id\": \"$SELLER_AGENT_ID\",
    \"initial_amount\": 100.00,
    \"max_rounds\": 5
  }")

SESSION_ID=$(echo $START_RESPONSE | jq -r '.session_id')
STATUS=$(echo $START_RESPONSE | jq -r '.status')
echo "Session ID: $SESSION_ID"
echo "Status: $STATUS"

echo ""
echo "=== Step 4: Monitor negotiation progress ==="
for i in {1..10}; do
    echo "Checking progress... (attempt $i)"
    
    PROGRESS=$(curl -s -X GET $API_URL/a2a-bargaining/progress/$SESSION_ID \
      -H "Authorization: Bearer $TOKEN")
    
    ROUND=$(echo $PROGRESS | jq -r '.round')
    CURRENT_AMOUNT=$(echo $PROGRESS | jq -r '.current_amount')
    ACTION=$(echo $PROGRESS | jq -r '.action')
    ACTOR=$(echo $PROGRESS | jq -r '.actor')
    
    echo "Round: $ROUND, Amount: $CURRENT_AMOUNT, Actor: $ACTOR, Action: $ACTION"
    
    if [ "$ACTION" == "completed" ] || [ "$ROUND" -eq 5 ]; then
        echo ""
        echo "=== Negotiation Completed! ==="
        echo "Final Amount: $CURRENT_AMOUNT"
        break
    fi
    
    sleep 2
done

echo ""
echo "=== Test Complete ==="
```

## Agents.json Configuration Options

### Volatility Levels

**Low (0.0 - 0.3):**
- Conservative counteroffers
- Smaller discount/markup changes
- Slower to reach agreement
- More predictable behavior

**Medium (0.3 - 0.7):**
- Balanced counteroffers
- Moderate discount/markup changes
- Good balance of speed and predictability

**High (0.7 - 1.0):**
- Aggressive counteroffers
- Larger discount/markup changes
- Faster negotiations (may walk away)
- Less predictable behavior

### Bargaining Styles

**Buyer Styles:**
- `"moderate"` - Balanced approach, gradual discounts
- `"aggressive"` - Large discounts quickly
- `"conservative"` - Small discounts, slow negotiations

**Seller Styles:**
- `"firm"` - Strong margins, slow to accept
- `"flexible"` - Lower margins, quick to accept
- `"dynamic"` - Adaptive based on round count

## Error Handling

### 1. Agent Not Found
```bash
Error: 404 Not Found
{
  "error": "buyer agent not found"
}
```

**Solution:** Verify agent IDs and create agents first

### 2. Invalid Agent Type
```bash
Error: 400 Bad Request
{
  "error": "buyer agent must be of type 'shopping'"
}
```

**Solution:** Ensure buyer is type "shopping" and seller is type "merchant"

### 3. Session Not Found
```bash
Error: 404 Not Found
{
  "error": "negotiation session not found"
}
```

**Solution:** Verify session_id from start negotiation response

### 4. A2A Message Failed
**Logs:**
```
ERROR failed to send A2A counteroffer session_id=a2a-nego-123 round=2 error=dial tcp connection refused
```

**Behavior:** System retries 3 times with 1s delay, then logs error and continues
